# raiyan.contact

This repository is an alternative to [linktr.ee/raiyan_contact](https://linktr.ee/raiyan_contact).

A visitor can start a call with a tap on the displayed **Call me** button. There is no need to copy or type the number. WhatsApp, email, and other profiles work the same way — one touch.

Live: [mdraiyanalam.github.io/raiyan.contact](https://mdraiyanalam.github.io/raiyan.contact/)

This is **not** a portfolio. It is only a contact / link hub. The portfolio is [mdraiyanalam.github.io/mdraiyanalam](https://mdraiyanalam.github.io/mdraiyanalam/).

## Local preview

Open `index.html` in a browser. Keep `img/PP picture.jpg` next to it.

## Deploy

```bash
git add index.html README.md
git commit -m "Linktree-style tap-to-call page"
git push origin main
```

GitHub Pages serves `main`. Use relative image paths (`img/...`), not `/img/...`.
